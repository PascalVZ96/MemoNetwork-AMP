# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/PascalVZ96/MemoNetwork-AMP
```

Go into the repository

```bash
cd MemoNetwork-AMP
```

Install

```bash
sudo bash ./scripts/install.sh ADS01
```

Refresh AMP

```
Ctrl + Shift + R
```
